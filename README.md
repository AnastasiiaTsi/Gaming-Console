# 🕹️ Pico Arcade: Retro Gaming Console 5-in-1

Універсальна портативна ретро-консоль, побудована на базі мікроконтролера **Raspberry Pi Pico** та мови **MicroPython**. Проєкт об'єднує 5 класичних аркадних ігор під керуванням єдиної модульної системи станів (State Machine).

>  **Розроблено в межах практичного курсу з вбудованих систем (Embedded Systems).**

---

## Апаратна архітектура (Hardware Setup)

Проєкт розрахований на роботу з наступним сетапом компонентів:
* **Обчислювальний модуль:** Raspberry Pi Pico (чип RP2040)
* **Дисплейний модуль:** Pico Display Pack (1.14" IPS LCD, драйвер **ST7789VW**, 240x240 px)
* **Органи керування:** 4 тактові кнопки (A, B, X, Y) + 5-позиційний аналоговий джойстик

### Схема розпіновки (Pin Mapping)

| Назва компонента | Пін мікроконтролера (GP) | Ігрова функція | 
| :--- | :---: | :--- |
| **Кнопка A** | `GP15` | Рух вгору ($\uparrow$) / Стрибок |
| **Кнопка B** | `GP17` | Рух вниз ($\downarrow$) |
| **Кнопка X** | `GP19` | Рух вліво ($\leftarrow$) |
| **Кнопка Y** | `GP21` | Рух вправо ($\rightarrow$) |
| **Джойстик (Центр/Ctrl)** | `GP3` | Кнопка **OK** / Повернення в меню |

---

## Ігрові режими та механіки

### 1. Ping-Pong
* **Опис:** Модифікована класична аркада.
* **Технічна реалізація:** Використовує вектори швидкості для обчислення траєкторії м'яча. Реалізовано випадкову зміну кута та швидкості відскоку м'яча при колізії з ракеткою гравця, що повністю унеможливлює передбачуваність траєкторії.

### 2. Snake
* **Опис:** Легендарна гра "Змійка" у дискретному просторі екрана.
* **Технічна реалізація:** Динамічний масив пар координат списку `list` для збереження тіла змії. Реалізовано алгоритми перевірки самоперетину (колізія голови з елементами хвоста) та випадкової генерації об'єктів їжі на сітці координат.

### 3. Space Attack
* **Опис:** Космічний скролл-шутер.
* **Технічна реалізація:** Обробка динамічних масивів для одночасного прорахунку координат декількох ворогів та випущених снарядів. Використовує матричний алгоритм перевірки колізій (AABB bounding box) для фіксації влучань.

### 4. Maze Runner
* **Опис:** Топологічний лабіринт на проходження.
* **Технічна реалізація:** Карта лабіринту задана статичною матрицею стін. На кожному ігровому такті алгоритм робить попередній прорахунок кроку гравця і блокує переміщення (рух назад), якщо зафіксовано накладання координат на межі стіни.

### 5. Dino Jump
* **Опис:** Нескінченний раннер з перешкодами.
* **Технічна реалізація:** Стрибок персонажа розраховується за квадратичною функцією, що імітує фізику вільного падіння під дією сили тяжіння. Перешкоди генеруються з правого краю екрана із поступовим прискоренням.
